# Retrieval eval: recall@k and MRR

> Status: model-free baselines only. The nightly build sandbox cannot download sentence-transformers models, so the MiniLM row comes from a local run of `notetaker eval-retrieval --embedder hashing-512 --embedder sentence-transformers/all-MiniLM-L6-v2 --max-words 120 60 -o reports/retrieval.md` (needs `pip install -e ".[rag]"`), which overwrites this file. The demo lectures are hand-written and short, so treat these numbers as a smoke test of the method; the real figures need labeled questions on the OCW lectures.

Question set: `eval/retrieval/questions.json` (26 questions, 4 lectures). Index: 20 passages. Generated by `notetaker eval-retrieval`.

recall@k: share of answer spans found in the top k passages. MRR: mean of 1 / rank of the first relevant passage (0 if not in the top 10). Chance: expected score of a random ordering. With 26 questions, one question is worth about 0.04, so smaller gaps are ties.
